# CSS

> Responsável por definir a aparência e o estilo de uma página na web.

---

## 📖 Sobre

CSS (Cascading Style Sheets) é utilizado para estilizar páginas desenvolvidas com HTML.

Enquanto o HTML organiza o conteúdo, o CSS define como esse conteúdo será apresentado, como cores, fontes, espaçamentos, tamanhos e posicionamento dos elementos.

Com o CSS também é possível criar layouts responsivos, animações e adaptar a interface para diferentes dispositivos.

## Principais conceitos

### Seletores

Permitem escolher quais elementos receberão um estilo.

Exemplo:

```css
h1 {
  color: blue;
}
```

---

### Classes e IDs

São utilizados para identificar elementos específicos e aplicar estilos de forma mais organizada.

---

### Cascata

Quando mais de uma regra pode ser aplicada ao mesmo elemento, o CSS utiliza uma ordem de prioridade para decidir qual será usada.

---

### Especificidade

Alguns seletores possuem maior prioridade do que outros.

Entender esse conceito ajuda a evitar conflitos entre estilos.

---

### Box Model

Todo elemento é formado por:

- Content
- Padding
- Border
- Margin

Esse modelo ajuda a entender como o espaço é distribuído na página.

---

### Display

Define como um elemento será exibido.

Alguns valores comuns:

- block
- inline
- inline-block
- flex
- grid

---

### Position

Controla o posicionamento dos elementos.

Os principais valores são:

- static
- relative
- absolute
- fixed
- sticky

---

## Resumindo

- CSS define a aparência de uma página.
- Trabalha em conjunto com o HTML.
- Ajuda a criar interfaces organizadas e responsivas.
- Entender conceitos como Box Model e Cascata facilita muito o desenvolvimento.
