# Flexbox

> Um modelo de layout do CSS que facilita o alinhamento e a distribuição dos elementos na página.

---

## Sobre

Flexbox (Flexible Box Layout) é uma ferramenta do CSS criada para facilitar a organização dos elementos dentro de um container.

Com ele, é possível alinhar itens, distribuir espaços e criar layouts de forma muito mais simples do que utilizando técnicas antigas.

Hoje, o Flexbox é uma das principais ferramentas para construir interfaces responsivas.

---

## O que eu entendi

Muitas situações podem ser resolvidas com poucas propriedades, antes de utilizar o Flexbox, é importante pensar em quem será o container e quais elementos serão os itens que ficarão dentro dele.

---

## O que mais me chamou atenção

A organização dos elementos.

Com apenas algumas linhas de CSS é possível centralizar conteúdos, distribuir espaços igualmente ou alterar a direção dos itens.

Isso torna o código mais limpo e facilita bastante a construção de layouts.

## Propriedades mais utilizadas

### display: flex;

Ativa o Flexbox no elemento pai.

---

### flex-direction

Define a direção dos elementos.

Valores mais comuns:

- row
- row-reverse
- column
- column-reverse

---

### justify-content

Controla o alinhamento dos elementos no eixo principal.

Alguns valores:

- flex-start
- center
- flex-end
- space-between
- space-around
- space-evenly

---

### align-items

Alinha os elementos no eixo cruzado.

Valores comuns:

- stretch
- flex-start
- center
- flex-end

---

### gap

Define o espaçamento entre os elementos.

---

### flex-wrap

Permite que os elementos quebrem para outra linha quando necessário.

Valores:

- nowrap
- wrap
- wrap-reverse

---

## Quando usar Flexbox?

O Flexbox é uma boa escolha para:

- Menus de navegação.
- Barras de ferramentas.
- Cards.
- Botões alinhados.
- Formulários.
- Componentes organizados em linha ou coluna.

---

## Resumindo

- Flexbox facilita a criação de layouts.
- Funciona organizando elementos dentro de um container.
- Possui propriedades que controlam alinhamento, direção e espaçamento.
- É uma das ferramentas mais utilizadas no desenvolvimento Front-end.
