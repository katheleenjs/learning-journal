# HTML

> A linguagem de marcação responsável por estruturar o conteúdo de uma página na web.

---

## Sobre

HTML (HyperText Markup Language) é a linguagem utilizada para criar a estrutura de uma página. É através dela que organizamos títulos, textos, imagens, links, formulários e outros elementos que aparecem em um site.

O HTML não é uma linguagem de programação. Seu papel é estruturar o conteúdo para que o navegador consiga interpretá-lo corretamente.

---

## O que eu entendi

Com o tempo, percebi que ele funciona como a base da construção. Primeiro organizamos a estrutura com HTML, depois utilizamos CSS para definir a aparência e JavaScript para adicionar interações.

---

## Como quero aplicar

Quero criar o hábito de escrever HTML de forma organizada e semântica, utilizando cada elemento para a função correta.

Acredito que construir uma boa estrutura desde o início facilita tanto o desenvolvimento quanto a manutenção dos projetos no futuro.

---

## Principais elementos

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`
- `<form>`
- `<button>`
- `<img>`

---

## Resumindo

- HTML define a estrutura de uma página.
- Não é uma linguagem de programação.
- Utilizar as tags corretas melhora a organização do código.
- Um HTML bem estruturado facilita acessibilidade, SEO e manutenção.
