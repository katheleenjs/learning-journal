# User Flow

> O caminho que o usuário percorre para realizar uma tarefa dentro de um produto.

---

## Sobre

User Flow é a representação do caminho que um usuário faz para alcançar um objetivo dentro de um produto digital.

Ele mostra quais etapas, decisões e ações fazem parte desse processo, ajudando a visualizar como as pessoas navegam entre diferentes telas ou funcionalidades.

Criar um User Flow é uma forma de organizar a experiência antes mesmo de começar a desenhar as interfaces.

---

## O que eu entendi

Quando comecei a estudar UX, eu achava que o User Flow era apenas um desenho mostrando a sequência de telas.

Depois de aprender mais sobre o assunto, percebi que ele ajuda a pensar na experiência do usuário de forma mais estratégica.

Antes de criar uma interface, é importante entender quais caminhos o usuário pode seguir, onde podem surgir dúvidas e como tornar o processo mais simples.

---

## O que mais me chamou atenção

Nem todos os usuários seguem exatamente a mesma sequência de ações. Alguns podem voltar para uma etapa anterior, desistir no meio do processo ou encontrar obstáculos que não estavam previstos.

Isso mostra como é importante pensar em diferentes possibilidades durante o planejamento.

---

## Como quero aplicar

Quero utilizar User Flows para organizar minhas ideias antes de começar a desenhar telas.

Acredito que visualizar o caminho do usuário pode ajudar a identificar etapas desnecessárias e criar experiências mais simples e intuitivas.

Também quero praticar esse processo para desenvolver um olhar mais atento à forma como as pessoas interagem com os produtos.

---

## Como um User Flow é formado

Normalmente um fluxo inclui:

- Ponto de entrada.
- Ações realizadas pelo usuário.
- Decisões (sim ou não).
- Próximas etapas.
- Objetivo final.

---

## Exemplo simples

Objetivo: Fazer login em um aplicativo.

1. Abrir o aplicativo.
2. Selecionar "Entrar".
3. Digitar e-mail e senha.
4. As informações estão corretas?

- Sim → Acessa a conta.
- Não → Exibe uma mensagem de erro e permite tentar novamente.

---

## Por que ele é importante?

- Ajuda a visualizar toda a experiência.
- Facilita a identificação de etapas desnecessárias.
- Melhora a comunicação entre a equipe.
- Serve como base para Wireframes e Protótipos.

---

## Resumindo

- User Flow representa o caminho que o usuário percorre.
- Ajuda a organizar a experiência antes da criação das telas.
- Permite identificar problemas e oportunidades de melhoria.
- É uma ferramenta importante durante o planejamento de um produto.
